# Byline

The credit every toolkit view carries: the toolkit, its author, the version, and where to cite it.

**Use**
- Every toolkit page ends with a Byline. In a chat panel, the one-line version; on a full page or an exported record, `full` adds the author's one-sentence bio.
- This is the toolkit's only branding. Inside someone's chat, everything else follows the system.
- Never remove or reword it; it ships with the toolkit's licence and citation.

**Props** `version` · `full`.

**Plain HTML**
```html
<footer class="aat-byline"><span><b>AI Anthropology Toolkit</b> by Matt Artz</span>
  <span class="aat-id">v3.11.0</span> <a href="https://doi.org/10.5281/zenodo.16728812">Cite (DOI)</a> …</footer>
```
