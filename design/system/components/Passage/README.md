# Passage

A participant's words, set large in the serif so they never read as interface text and are the first thing the eye lands on.

**Use** for every quoted chunk, field note or document excerpt. Always give the `source` (chunk ID, speaker) so it can be traced. Quote exactly; never trim or tidy the words.

**Props** `children`: the words · `source`.

**Plain HTML**
```html
<figure class="aat-passage">
  <blockquote>I put stuff in because I had extra.</blockquote>
  <figcaption>P07-c15 · Participant 7</figcaption>
</figure>
```
