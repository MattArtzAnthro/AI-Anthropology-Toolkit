# CodeTag

A code's name with its colour dot, used wherever a code is named outside a choice.

**Use** the same `tone` for a code everywhere: tags, networks, charts. Six tones; past six, repeat them and rely on the name. The dot is a mark only; the name carries the meaning.

**Props** `tone`: 1–6 · `children`: the code's label.

**Plain HTML** `<span class="aat-code aat-code--2">Charity framing</span>`
